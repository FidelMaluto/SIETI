O SIETI é um sistema que possibilita fazer o controle de materias informátiocos, dando segurança as empresas que os gerem.
É um sistema destinado ao resgisto, controlo, monitorização e atualização de ativos tecnológicos...

Objetivos:
    *Organizar os equipamentos;
    *Controlar e gerir inventário para a segurança da informação;

Requisitos Funcionais
    RF01 Cadastro de usuários
    RF02 Autenticação
    RF03 Cadastro de equipamentos
    RF04 Edição de equipamentos
    RF05 Exclusão de equipamentos
    RF06 Listagem de equipamentos
    RF07 Controle de movimento
    RF08 Pesquisa e filtro
    RF09 Histórico de alterações
    RF10 Relatórios

Requisitos Não Funcionais
    RNF01 Segurança
    RNF02 Usabilidade
    RNF03 Desempenho
    RNF04 Confiabilidade
    RNF05 Manutenibilidade
    RNF06 Portabilidade
    RNF07 Escalabilidade
